这些是根据 Game Studio 的材质、字体、配色、动效与层级要求提出的项目候选主题，并非插件自带或强制指定的主题。插件面向浏览器游戏的实现建议不改变本项目 Godot 引擎要求。正式实现仍使用 Godot Control/Theme 与独立分层素材。

对照板不是精确像素布局：落地时在 1440×900 画布中为角色设置约 540×675 的参考区域，置于右半屏，并以实际可见轮廓校正大小。标题、按钮、人物分别实现，不能把整张样稿贴作可交互菜单。最终人物素材须保留用户确认姿态和 v1 身份特征。

## 当前入口与按钮接入核查

`project.godot` → `scenes/main.tscn` → `scripts/ui/main.gd._ready()` → `show_intro()`。启动场景采用 1440×900 逻辑画布。通用 `clear_page()` 会添加章节顶部栏，独立主菜单须绕过这层通用顶部栏。

| 按钮 | 已有能力 | 尚需明确的行为 |
|---|---|---|
| 新的探索 | `begin_expedition(false)` 可开启新远征，保留永久收藏、装备、已领取奖励及调查进度 | 建议沿用永久收藏规则，不将按钮解释为删除存档 |
| 继续探索 | 已保存永久收藏、调查进度等；无当前远征节点、生命等断点存档 | 需在接入前确认是返回据点，还是增加探索安全节点续玩；不能把文件存在当作已有可继续远征 |
| 显现权柄 | 已有收藏与装备页面 `show_collection()` 和卡牌图鉴 `show_catalog()` | 用户尚未指定打开哪类权柄页面 |
| 探索手札 | `show_journal()` 可显示第一章调查记录弹窗 | 可复用，关闭返回主菜单 |
| 退出游戏 | Godot `get_tree().quit()` | 接入菜单退出动作 |

建议以独立 `scripts/ui/start_menu.gd` 负责布局与信号，单一集成者修改 `scripts/ui/main.gd`。素材使用专用新目录，选定主题后再制作独立素材并接入。当前未修改以上生产文件。
