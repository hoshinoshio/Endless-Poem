# 2026-10-05 角色、环境运动与战斗 UI 验收清单

> 本文保留上一版实际验收。2026-10-06的用户确认已将HUD改为仅无数值血条、流光改为八路圆周外散，并强化半透明钟表投影；对应旧显示要求不再用于当前验收。最新记录见 `clock_health_revision_2026-10-06.md`。

## 文档用途与状态

本清单用于本轮角色地图运动、法术流光、法阵、战斗 UI 和卡牌面板的集成后验收。资源和实现已进入独立源码复核；连续 GPU 运行证据尚未提供。静态源码复核可以确认资源绑定和时间推进逻辑，不能替代实际画面上的运动、循环、尾迹衰减及遮挡验收。

## 已确认基线（来自项目现有规则）

- 月璃战斗形象为主角，保留既定身份：对应原始角色高度 310 px 的 70%，战斗显示高度约 217 px（不是屏幕高度的 70%）；无书作为施法源，施法源为身后的时间权柄。
- 星台沿用已确认的精细像素旧铜观测台设定。本轮不得把其他未确认场景或角色造型写成定案。
- 卡库为 6 列×2 行的实体卡装备列表；收藏可超过 12 张并滚动，装备数量不设上限。卡牌使用后留在原装备位置并各自冷却。
- 探索获得的卡永久加入收藏；每张卡为独立实体副本，拥有独立冷却。
- 普通敌人状态栏在对应敌人上方；Boss 状态栏在画面顶部中央，距顶部约 90 px。

## 本轮新增视觉要求（按用户 2026-10-05 指示）

- 角色、地图和怪物呈现运动。
- 法术流光沿路径运行，尾迹在后方逐渐消散。
- 法阵放大。
- 美化战斗 UI。
- 渲染卡牌设计。

这些描述限定方向，不授权新增技能、游戏数值、怪物设定或其他世界观事实。验收只判断可见行为和已确认规则是否落实。

## 独立源码与资源复核（2026-10-05）

以下只表示对当前可读源码、清单和图片资源的核对结果，不表示已在 GPU 上运行通过：

- **源码已核对：角色帧不是单张图平移/抖动。** `chapter1_assets.gd` 为主角及六类战斗角色/怪物加载独立 idle 图集；`idle_motion_assets.gd` 将四个独立裁切帧装入循环 idle `SpriteFrames`，设置为 4 FPS。`combat_actor.gd` 逐帧推进 SpriteFrames，采用真实战斗时间；从主角 idle 图集目视可见四个姿势裁切，而非一张图的容器位移。姿势差异较细，是否在实际战斗尺度下清晰可辨仍待连续画面检查。
- **源码已核对：环境有多个局部运动驱动。** 启用 `ambient_motion` 时，背景 shader 使三处布旗量化位移、七处灯光随时间变化；`environment_motion.gd` 另使两个星仪刻线转动并使星点亮度变化。由源码可确认这些局部效果使用战斗时钟更新；可见幅度、画面质量和相互遮挡仍待 GPU 画面检查。
- **源码已核对：流光与法阵逻辑。** `time_authority_fx.gd` 设置 `radius = 150`，绘制三层旋转刻度，因此设计直径为 300 px；每次对目标施法创建五道不同延迟/路径的流光，路径前端随进度移动，历史点以 0.16 秒寿命渐隐并在到期后清除。有效运行时尺寸、前端可辨性、尾迹是否表现为用户期待的渐消效果仍待 GPU 连续帧核验。
- **源码/资源已核对：九类卡面接入。** `battle_card.gd` 按卡牌 type 载入 `assets/cards/<type>.png`，并绘制名称、费用、冷却进度或状态。资源目录中存在首章九种卡的对应图片。实际导入显示、插画裁切、文字可读性及各种卡牌状态仍待运行时画面检查。
- **源码已核对：战场和卡库边界。** 项目视口为 1440×900，战场为 y=80 至 y=568；卡库视口位于 y=572 至 842，打开后与战场保留 4 px 间隔。人物状态区位于卡库下方；既有验收脚本包含 Boss 血条 y=90、普通敌人血条在角色上方和点击区域不被状态栏拦截的检查。当前卡牌尺寸为 168×128、6 列，两行可见且可滚动。以上布局仅源码静态核对，尚未用本轮 GPU 运行画面确认遮挡/可读性。
- **源码已核对：暂停与查看行为分开。** 战斗时间暂停时 `combat.tick` 不推进，战场 `advance` 收到零战斗时间，角色、环境与流光动画按战斗时钟冻结；开关卡库/滚动本身不触发暂停。普通模态面板会暂停战斗，关闭后恢复。实际交互无误仍待运行验收。
- **源码已核对：未发现美术接入自动获卡路径。** 卡面组件只读取数据并绘制；战斗奖励领取仍通过已有显式领取回调和 `store.claim_reward`，新奖励不自动装备。仅完成静态代码路径核对，完整存档/重复领取行为不属于本次动态视觉验收。
