**原文明示**

**可直接转成构图锚点**：暮色中的观测环、灯廊、星台阶梯、钟楼回廊、大钟、下层平台石桥；一侧呈现“落日前”完整桥梁与重复日常，另一侧呈现“钟鸣后”断桥、碎灯、飘带；天空停留在星升将临而夜色未至的时刻。切片分区、镜头、具体建筑样式和色彩分配仍需设计决定。

**待定**：星台文明/建筑的具体文化形制、比例与平面布局；观测设备、大钟、灯具、栏杆和桥的美术语言；天空星象、灾难本身如何显现；场景是否采用单张背景、分层卷轴或独立场景块；实际游戏镜头和原生像素尺寸。文稿的故事细节是明确锚点，不等于已经批准的关卡背景图。

### 黄铜星仪

**原文明示**：敌人表（源文 P99 / 来源摘录 T99）定位为守护单位，设锚保护友方；其名称含“黄铜星仪”。P115提到本章减速采用统一的旧铜刻度、轻微拖影与音高变化，但这是全局减速呈现规则。

**造型线索的边界**：“黄铜星仪”是名称，“设锚/护持”是战斗职能。两者可供美术提案参考，但原文未明确它是仪器、构装体、穿戴者或其组合，也没规定黄铜外观、星盘/指针、体型、肢体或颜色。不能把名称直接当作确认的机械怪物设定。

**待选**：主体是生物、残像、器物或复合体；“星仪”和“锚”的可见关联；保护动作如何表现、锚实体放在哪里；轮廓和与卫兵的阵营关系。

**原文明示**：敌人表（源文 P99 / 来源摘录 T99）定位为支援单位；“复述”会标记友方攻击，并在攻击命中后延迟复演一半伤害。P14称观测员会重复调校镜筒观看同一场星升。P24称暮笙是当晚负责敲撤离钟的观测员，且是唯一记得每次循环的映像。

**待选**：是否携带镜筒、观测工具或记录器；复演标记/延迟攻击的视觉符号；人形/残像程度、站姿、服饰与配色。

### 整点卫兵（精英）

**原文明示**：敌人表（源文 P99 / 来源摘录 T99）定位为攻击型精英；每第三次行动从普通刺击改为蓄力更久的重刺。P92明确要求精英“以新增行为区分，不只换色”。

**待选**：新增行为用什么轮廓、动作、武器、护具或时间刻度表现；怎样让精英与普通巡刻卫兵一眼可辨。具体差异造型还没有文稿依据。

### 克洛诺斯·试炼相

**原文明示**：P30写克洛诺斯在时间锚前展开试炼相；P94（源文）/来源摘录 P103-P104 明确：“试炼相由引导立绘的刻度环与星门纹样展开而成，让玩家认出这是同一个人。”这是当前最明确的Boss视觉描述。阶段意象依次为继续前进的时间、被锚定保留的状态、不断复演的记忆（P31；阶段规则在 T105）。

**提案边界**：来源原文标注阶段划分、行动与数值为新增内容。刻度环和星门纹样有明确文字锚点；具体Boss身形变化、分身数量、颜色、形体、动画方式及阶段外观未规定。

**待选**：是否保留引导立绘中的同一克洛诺斯形体、试炼相展开幅度、刻度环/星门的具体形状、各阶段差异、受击/回收/残响表现，以及Boss与时间锚的构图关系。不要只凭“克洛诺斯”名称推演神话服装或把他设计为尤格本体；原文确认他是尤格索托斯化身与引导者，但本战检验的是月璃对时间的理解，不等于击败尤格本体（源文 P43、P46）。

### 时间锚

**原文明示**：P25称其在大钟下，由暮笙启动以冻结黄昏；P30和P36明确锚位于大钟下/大钟前；Boss阶段表（来源摘录 T105、P108-P109）规定它可被攻击击破、负责记录Boss生命并关联回收。P99称锚没有行动条，任何单体攻击均能击破。

**待选**：锚的实体形状、数量/尺寸、悬挂或落地方式、与大钟的机械/魔法关系、发光与动画；它是否像钟摆、钉、晶体、符文或其他形态都没有被文稿指定。游戏规则里“锚”是玩法名词，不足以确定其视觉轮廓。
