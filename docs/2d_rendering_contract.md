## 接口

CombatStage extends Node2D：configure(encounter, assets)、sync_snapshot(snapshot)、consume_events(events)、advance(real_delta, battle_delta)、get_target_rect(id)，signal target_selected(id)。actors[player] 为月璃，敌人使用战斗实体 ID；missing_assets 明确记录缺素材。

main.set_battle_visual_assets(manifest) 是显式接入入口。只有场景、主角、当前敌人以及动态锚素材完整时才启用新表现层；动画缺帧须明确报告，不能把静态图位移冒充逐帧动画。素材不足时不自动生成替代造型。

正式素材须保存在本工程内；测试纹理只在 tests 中构造。测试用颜色纹理不能作为最终视觉验收证据。
